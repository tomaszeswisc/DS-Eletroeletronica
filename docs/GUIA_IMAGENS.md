# Capturas autênticas dos diagramas Wokwi

Capturas feitas em 15/10/2026 no editor web do [Wokwi](https://wokwi.com/projects/new/arduino-uno), carregando o conteúdo integral de cada `diagram.json` do commit [`290b4c2`](https://github.com/tomaszeswisc/DS-Eletroeletronica/commit/290b4c290d505ae68102f9882a70f4930c9f0e1a).

As imagens mostram a visualização real do editor, com a simulação parada. **Não comprovam compilação, execução, funcionamento elétrico ou testes físicos.** O código, os diagramas e as configurações originais foram preservados. As imagens não foram geradas por IA e foram mantidas em JPEG, formato nativo da captura do navegador.

## Atualização das capturas

1. Carregue o `diagram.json` integral e confira a versão de origem.
2. Enquadre todos os componentes e fios, com o menu fechado.
3. Capture diretamente o editor e mantenha o formato real do arquivo.
4. Atualize a imagem, seu vínculo no guia individual e o SHA nesta tabela.
5. Só registre execução bem-sucedida após compilar e executar o código correspondente; uma imagem do editor não basta.
